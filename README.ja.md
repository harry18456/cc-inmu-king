# inmu-king

Claude Code 用のネタ mod です。あなたか Claude が淫夢語録を打つたびに、プロンプトの上の band に **T A D O K O R O** の文字が灯ります。灯った文字は虹色に塗り分けられ、横には「+3 田所浩二」が 2 秒間出ます。8 文字そろうと**バースト**です。定番の語録と動くドット絵が出て、8-bit のジングルが鳴り、#20 から始まるランキングを一つ上がります。#1 に届くと**戴冠**です。ドット絵の群衆が踊り、ファンファーレが鳴り、Claude の次の返答は「やりますねぇ！」で終わります。見つけた語録は語録図鑑に集まり、ターンの終わりに出る秒数は 114514 だけの式に書き換わります。

![114514 と打つとバースト：文字が全部灯り、虹色の数字が光る。Claude の返答でもバーストし、王冠の野獣が出る。最後は戴冠で、ドット絵の群衆が踊る。](docs/burst.gif)

<sub>画面は英語表示です。</sub>

2026 年 8 月 10 日に公開された AI 生成曲『INMU KING』と、20 年来の淫夢文化から着想を得ました。曲から借りたのはタイトルだけです。掛け声と称号は曲より前からある語録か、この mod オリジナルの台詞です。ドット絵と効果音もすべてオリジナルです。

## 見た目

```
T A D O K O R O  #17 下北沢の新入り  i: パネル      ← 普段の band
T A D O K O R O  +3 田所浩二 NEW!  #17 …           ← 得点、2 秒
T A D O K O R O  +8 114514 NEW!                    ← バースト、3 秒：
いいよ！こいよ！                                      得点、掛け声、ドット絵
（ドット絵、3 種類を順番に：目が光る王冠の野獣、
  だんだん減っていくアイスティー、虹色の 114514）
👑 INMU KING 降臨 👑                                ← 戴冠、6 秒
（王冠をかぶったドット絵の 3 人が、手を上げ下げして踊る）
```

![演出の合間の band：T A D O の 4 文字が虹色に灯り、順位は #12。](docs/band.png)

灯った文字は虹色、消えている文字は灰色です。得点で灯ったばかりの文字は、2 秒間だけ反転表示になります。バースト中は演出として 8 文字すべてが灯ります。演出が終わると実際のゲージに戻り、8 を超えた分はもう灯っています。band をオフにすると、順位はプロンプト下のステータスラインに出ます：`淫夢 #17 下北沢の新入り · T A D O K o r o`。大文字が灯った文字、小文字が消えている文字です。

ターンの終わりの行では、秒数が 114514 の式になります：

![Churned for -11+4-5+14 s](docs/turn-line.png)

## 得点

| 打った語録 | 灯る文字数 |
|---|---|
| `114514`、`1919810` | 8、即バースト |
| `INMU KING`、`淫夢の王` | 5 |
| `田所浩二`、`野獣先輩`、`24歳、学生です`、`屋上あんだけど`、`野獣の眼光`、`11:45:14` | 3 |
| `いいよ！こいよ！`、`やりますねぇ`、`イキスギ`、`ンアッー`、`アイスティー`、`暴れんなよ`、`見ろよ見ろよ`、`ぬわああああん`、`それ一番言われてるから`、`ホモビ`、`BB先輩`、`野獣の日` | 2 |
| `淫夢`、`悪臭`、`迫真`、`下北沢`、`1919`、`810`、`MUR`、`KMR`、`TDN` | 1 |

- 数字と英単語は、独立したトークンのときだけ数えます。前後に英字・数字・アンダースコアが付いていると数えません：`port 8100` は 810 ではなく、`build114514x` は 114514 ではなく、`INMU KINGDOM` は INMU KING ではありません。数字の直後に草（小文字の w の連続）が続いても、その数字は数えます：`114514www`。日本語や中国語が隣にあっても数えます：`MUR大先輩`、`tadokoroさん`。
- `$` の後、小数の中、`ファイル名:行番号` の中の数字は数えません：`$1,810`、`1.1919`、`foo.ts:810`。`1145141919810` は大当たり 2 つを同時に取ります。
- 全角数字と半角カナも同じく数えます：`１１４５１４`、`ｲｷｽｷﾞ`。いくつかに分かれる語録は、間に空白や句読点が入っても数えます：`いいよ、来いよ`、`いいよ・こいよ`、`見ろよ 見ろよ`。語録を含むだけの普通の言葉は数えません：`サインアップ`、`ファッション`、「ぇ」の付かない「やりますね」。
- 一つのテキストの中で、同じ語録は 1 回だけ数えます。一つのテキストで入るのは最大 16 点（ゲージ 2 本分）です。
- Claude 自身の返答も、半分の点数（切り上げ）で数えます。中断された返答とサブエージェントの返答は数えません。設定でオフにできます。
- エラーになったツール呼び出しと、拒否されたツール呼び出しは**罪**です。最初の 1 回と 5 回ごとに、一言のトーストとため息の音が出ます。
- ゲームはセッションごとに別々です。#20 から始まり（8 月 10 日は最初から戴冠）、点数・戴冠回数・図鑑はセッションが終わるまで残ります（ホットリロードや設定変更では消えません）。次のセッションはまた最初からです。

## 称号

| 順位 | 称号 |
|---|---|
| 20–16 | 下北沢の新入り |
| 15–11 | 24歳、学生 |
| 10–6 | 水泳部の先輩 |
| 5–3 | 野獣 |
| 2 | 野獣先輩 |
| 1 | 淫夢の王 INMU KING |

#10 からは、スピナーの文字が「ンアッー」「やりますねぇ」などに変わります。#1 では「INMU KING 👑」です。2 分を超えたターンのスピナーは「アイスティー準備中」になります。

## 語録図鑑

語録は初めて打たれたときに図鑑に入り、そのときの表示に `NEW!` が付きます。パネルには全 33 個が点数ごとに 5 行で並び、まだ見つけていないものは `???` になります。図鑑はセッションが終わるまで残ります。`/inmu reset` でも消えず、`/inmu reset all` で消えます。

![パネル：順位、累計、33 個中 25 個を見つけた語録図鑑。](docs/panel.png)

## 言語

`/config` の *Language* で、band・パネル・`/inmu` の返答の言語と、語録の横に付く意味の言語を選べます：

- `auto`（既定）：Claude Code 自身の言語設定に従います（`ja`、`Japanese`、`日本語` などの書き方を読み取ります）。設定がなければシステムのロケール、それもなければ英語です。
- `ja`：日本語。語録に意味は付けません。例：やりますねぇ。
- `en`：英語。例：やりますねぇ (not bad at all)。
- `zh-TW`：繁体字中国語。例：やりますねぇ（挺行的嘛）。

語録そのものは、どの言語でも日本語のままです。

## 効果音

`sounds/` にオリジナルの 8-bit ジングルが 4 つ入っています：得点、バースト、戴冠、罪。作ったのは `tools/make_sounds.py` で、Python の標準ライブラリだけで動きます。

**自分の音声ファイル**を次のフォルダに置くと、内蔵の音と差し替わります：

```
Windows: C:\Users\<ユーザー名>\.claude\inmu-king\sounds\
macOS:   ~/.claude/inmu-king/sounds/
```

`/config` の *Your sound folder* で、別のフォルダも指定できます。

| ファイル名 | 鳴るとき |
|---|---|
| `hit`、`burst`、`crown`、`sin` | 得点、バースト、戴冠、罪 |
| 語録の id：`iiyo`、`yarimasu`、`114514` | その語録を打ったとき |
| 語録の文字：`やりますねぇ`、`いいよこいよ`、`田所浩二` | 同上。句読点と空白は省けます |

- 形式：wav、mp3、m4a、wma、aac。
- 名前に `-2`、`-3` を付けると、順番に鳴るバリエーションを置けます：`burst.wav`、`burst-2.mp3`。
- 得点のときは、語録自身の音声が得点の音の代わりに鳴ります。バーストと戴冠のときは、語録の音声が先に鳴り、次にイベントの音が鳴ります。
- `/inmu sounds` でフォルダを読み直します。認識できたもの、できなかったもの、使える名前をすべて表示します。
- このフォルダはリポジトリの外にあるので、追加した音声ファイルがコミットされることはありません。

## 時刻ネタ

- 毎日 **11:45:14**：3 点と「淫夢時間」のトースト。そのとき開いている各セッションで、1 日 1 回です。
- **8 月 10 日**、野獣の日：その日はどのセッションも最初から戴冠しています。

## コマンド

```
/inmu              順位、文字、累計、図鑑を表示して、パネルを開く
/inmu burst        バーストのデモ：演出と音だけ。得点も順位も変わらない
/inmu king         戴冠のデモ：演出と音だけ。順位は変わらず、Claude にも感染しない
/inmu sounds       音声フォルダを読み直して一覧を出す
/inmu mute|unmute  このセッションをミュート／ミュート解除
/inmu reset        #20 に戻し、文字を消灯、累計をクリア。図鑑は残る
/inmu reset all    図鑑も消す
/inmu band on|off  band の表示／非表示（非表示の間、順位はステータスラインに出る）
/inmu homo 1919    数字を 114514 の式で書く
```

パネルは `/inmu` か、band の `i: パネル` ボタンで開きます。fullscreen モードならクリックできます。そうでなければ `ctrl+x` の次に `tab` を押して band にキー入力を渡し、`i` を押します。プロンプトに `i` と打っても押されません。パネルのボタンは 3 つです：ミュート（1）、リセット（2）、閉じる（0）。リセットしてもミュートは解除されません。Esc で閉じます。

## 設定（`/config`）

| 設定 | 既定 | 内容 |
|---|---|---|
| Sound effects | オン | すべての音。Windows は PowerShell、macOS は Claude Code で鳴らします。ほかのプラットフォームでは鳴りません。 |
| Your sound folder | 空 | 自分の音声ファイルを置くフォルダ。空なら `~/.claude/inmu-king/sounds` です。 |
| Infect Claude at #1 | オン | 戴冠の次の返答が「やりますねぇ！」で終わります。そのターンだけシステムプロンプトに 1 セクション足すので、プロンプトキャッシュが 1 回作り直されます。`-p` と SDK のセッションでは足しません。「JSON だけ」のように出力を指定されたときは、この一行を省くよう Claude に頼みます。これはモデルへのお願いで、保証ではありません。 |
| Claude's replies count too | オン | Claude の返答にある語録も、半分の点数で数えます。 |
| Show the band | オン | オフにすると band を描かず、順位はプロンプト下のステータスラインに出ます。ほかはそのまま動きます。 |

## 開発

```
claude plugin test .           # テスト 118 個、ネットワーク不要
claude plugin validate .
```

`tsc` には、Claude Code が mod を読み込むときに `.claude-plugin/types/` へ書き出す型が必要です（git では無視しています）。`claude --plugin-dir .` を一度起動して終了してから、`npx -p typescript tsc --noEmit -p .` を実行してください。

同じセッションで mod を 2 回読み込むと、2 つのコピーがそれぞれ別のゲームを動かし、band も 2 本出ます。セッション開始時に読み込んだ mod を、ホットリロードでもう一度加えたときに起こります。その場合はホットリロードせず、セッションを再起動してください。

## この mod がすること・しないこと

- 送信したプロンプトと Claude の返答を、文字列で照合するだけです。プロンプトは書き換えません。ネットワークにもモデルにもアクセスしません。
- モデルに届くのは戴冠のセクションだけで、これはオフにできます。
- 何も保存しません。ゲームはセッションの中だけにあり、Claude Code の plugin store は読みも書きもしません。以前のバージョンが残したセーブ（`~/.claude/plugins/store/inmu-king*.json`）はそのまま残り、読まれません。不要なら削除してください。
- 別の mod が描く band は、この band の下に表示されます。Claude Code が自身のフィードバックアンケートを出している間、この band は場所を譲ります。
- Windows では PowerShell が音声をバックグラウンドで鳴らすので、イベントから約 1 秒遅れて鳴ります。ターンを止めることはありません。
- ドット絵はターミナルにだけ描きます。デスクトップアプリでは文字だけです。

## 内容について

掛け声と称号は、広く知られた短い語録か、この mod オリジナルの台詞です。曲から借りたのはタイトルだけです。ドット絵と効果音もオリジナルです。語録の元になった人物は実在するため、この mod はご本人の顔を描かず、元動画の音声も同梱していません。`TDN` は表記法として数えるだけで、その元になった実在の名字は照合しません。追加する音声は、ご自身の責任でお使いください。
